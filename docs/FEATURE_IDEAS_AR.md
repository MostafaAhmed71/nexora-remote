# إضافات اختارها المستخدم

تاريخ الحفظ: 2026-11-03.

طلب المستخدم بدء التنفيذ. أضيفت نسخة تطوير محلية؛ تفاصيل التنفيذ والتحقق والقيود في [إدارة الماستر](MASTER_MANAGEMENT_AR.md). وضع الامتحان المقيد على مستوى النظام ما زال غير منفذ؛ الموجود مشغل حصة موجه.

1. **نقل الملفات:** نقل الملفات بين الجهازين، مع عرض تقدم النقل وإمكانية الإلغاء.
2. **إدارة أجهزة جماعية:** البحث والتصنيفات والملاحظات، وتنفيذ مهام على مجموعة أجهزة وفق الصلاحيات.
3. **إدارة وقت الأجهزة من جهاز ماستر:** تحديد مدة لكل جهاز أو مجموعة، وعرض الوقت المتبقي والتنبيه قبل انتهائه، مع تمديد الوقت وإيقافه مؤقتًا وإنهائه من الماستر. يستمر احتساب الوقت عبر إعادة التشغيل وانقطاع الاتصال، وتُسجل تغييرات الوقت ومن نفذها. التصور الحالي لنهاية المدة: شاشة قفل تمنع الاستخدام حتى يمنح الماستر وقتًا جديدًا؛ رد المستخدم كان تأكيدًا عامًا، لذلك إيقاف التشغيل الكامل ليس متطلبًا مؤكدًا.
4. **وضع الحصة أو الامتحان:** يحدد الماستر البرامج والمواقع المسموح باستخدامها أثناء الحصة أو الامتحان.
5. **قفل جماعي:** قفل استخدام مجموعة أجهزة وفتحها من جهاز الماستر.
6. **باقات وقت:** مدد جاهزة مثل نصف ساعة أو ساعة، مع إمكانية إنشاء باقة مخصصة وتطبيقها بسرعة.
7. **خريطة للأجهزة:** عرض الأجهزة حسب القاعة أو المكان، بألوان توضح المتاح والمشغول والوقت المتبقي.
